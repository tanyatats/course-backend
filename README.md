# Бэкенд курса tanya.tats

Приём оплаты за курсы через ЮKassa + автоматическая отправка PDF и
ссылки на курс покупателю после оплаты.

## Что делает

- `POST /api/pay` — создаёт платёж в ЮKassa (мини 10 000 / расширенный 50 000),
  спрашивает email покупателя, возвращает ссылку на оплату.
- `POST /api/webhooks/yookassa` — принимает уведомление об оплате,
  проверяет источник по IP и перепроверяет платёж напрямую в ЮKassa,
  затем шлёт письмо с PDF и ссылкой-токеном на курс.
- `GET /api/access/{token}` — фронт курса спрашивает, валиден ли доступ.
- `GET /api/health` — проверка живости.

## Порядок запуска (важно — именно в этом порядке)

Тут «курица и яйцо»: ЮKassa в анкете просит адрес вебхука, а адрес
появляется только после деплоя. Поэтому:

1. Задеплой бэкенд (шаги 1–5) — БЕЗ ключей ЮKassa. Получишь адрес
   вида `https://<random>.twc1.net`.
2. Впиши в анкету ЮKassa адрес вебхука
   `https://<random>.twc1.net/api/webhooks/yookassa` и email для реестров.
   Отправь анкету, дождись одобрения магазина и получи shop_id + ключ.
3. Впиши ключи в переменные окружения (шаг 4), передеплой.
4. Прогони тестовую оплату.

## 2. База данных (PostgreSQL)

На Timeweb App Platform файловая система эфемерная — SQLite слетит при
передеплое. Нужна managed-база:

1. Панель Timeweb → **Облачные базы данных** → создать **PostgreSQL**
   (минимальный тариф хватит).
2. Скопируй строку подключения — понадобится на шаге 4.
   Формат: `postgresql+psycopg2://user:pass@host:5432/dbname`

## 3. Создать приложение

1. Панель Timeweb → **App Platform** → **Создать приложение**.
2. **Backend → Python / FastAPI**.
3. Подключить GitHub, выбрать репозиторий `course-backend`, ветку `main`.
4. Команда сборки: `pip3 install --upgrade -r requirements.txt`
5. Команда запуска по умолчанию `uvicorn main:app --host 0.0.0.0` сработает
   (в корне есть шим `main.py`).

## 4. Переменные окружения

В настройках приложения → **Переменные**:

| Ключ | Значение |
|---|---|
| `DATABASE_URL` | строка подключения к Postgres из шага 2 |
| `YOOKASSA_SHOP_ID` | из кабинета ЮKassa (после одобрения магазина) |
| `YOOKASSA_SECRET_KEY` | из кабинета ЮKassa |
| `FRONTEND_RETURN_URL` | `https://tanyatats.ru/thanks.html` |
| `BACKEND_BASE_URL` | `https://tanyatats.ru` |
| `SMTP_HOST` | адрес SMTP-сервера (см. ниже) |
| `SMTP_PORT` | `465` (SSL) или `587` (STARTTLS) |
| `SMTP_USER` | логин почты |
| `SMTP_PASSWORD` | пароль почты (для Gmail — «пароль приложения») |
| `SMTP_FROM_NAME` | `tanya.tats` |
| `CORS_ORIGINS` | `https://tanyatats.ru,https://www.tanyatats.ru` |

### Про SMTP (отправку писем)

Два простых варианта:

**А. Почта на домене через Timeweb** (раздел «Почта» в панели).
Заведи ящик `info@tanyatats.ru`, тогда:
- `SMTP_HOST` = smtp-сервер timeweb (смотри в панели почты),
- `SMTP_USER` = `info@tanyatats.ru`,
- `SMTP_PASSWORD` = пароль ящика.
Солиднее для учеников (письмо приходит с твоего домена).

**Б. Gmail** `tzhighalkina80@gmail.com`:
- включи 2FA в Google-аккаунте,
- создай «пароль приложения» (App Password) в настройках безопасности Google,
- `SMTP_HOST` = `smtp.gmail.com`, `SMTP_PORT` = `465`,
- `SMTP_USER` = `tzhighalkina80@gmail.com`,
- `SMTP_PASSWORD` = сгенерированный пароль приложения (16 символов).
Проще, но Gmail имеет суточные лимиты и иногда помечает авто-письма как спам.

## 5. Деплой и проверка

1. «Развернуть» → Timeweb соберёт и запустит, выдаст URL `https://<random>.twc1.net`.
2. Открой `<url>/api/health` — должно быть `{"status":"ok","yookassa":false}`
   (false — пока нет ключей, это нормально).
3. Открой `<url>/docs` — Swagger со всеми эндпоинтами.

## 6. Подключение фронта (кнопки на сайте)

Сейчас кнопки на сайте ведут напрямую на платёжные ссылки ЮKassa.
Для автоматизации их нужно переключить на новый бэкенд: кнопка
открывает маленькую форму «введите email», которая шлёт
`POST <url>/api/pay` и редиректит на `confirmation_url`.
Готовый виджет-форму дам отдельным шагом после деплоя.

## 7. course.html — проверка доступа по токену

Страница курса при открытии берёт `?t=<token>` из адреса и спрашивает
`GET <url>/api/access/<token>`. Если ответ 404 — показывает «доступ
только после оплаты». Готовый скрипт для course.html дам после деплоя.

## Безопасность (что уже сделано)

- Webhook принимается только с официальных IP ЮKassa.
- Платёж перепроверяется прямым запросом в ЮKassa (не доверяем телу вслепую).
- Защита от повторной обработки (idempotency): письмо шлётся один раз.
- Ключи и пароли — только в переменных окружения, не в коде.

## Важно про чеки (самозанятость)

Чек по 54-ФЗ формируется в объекте платежа (`receipt` с email покупателя).
Но как самозанятая ты дополнительно обязана провести доход в приложении
«Мой налог» — это ЮKassa за тебя не делает. Одно ручное действие на продажу.
